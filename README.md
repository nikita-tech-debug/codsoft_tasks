CODSOFT Internship Tasks

This repository contains the three tasks completed as part of the CODSOFT Internship Program.

📋 Completed Tasks

1. Chatbot

A simple interactive chatbot that responds to user inputs using predefined responses and basic conversational logic.

Folder: "Chatbot/"

2. Recommendation System

A recommendation system that provides suggestions based on available data and similarity between items.

Folder: "Recommendation-System/"

3. Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game played on a 3×3 grid. The program checks for winning conditions and draw situations.

Folder: "Tic-Tac-Toe/"
